# DealFinder Landing Page

Ready-to-upload static website for GitHub Pages.

## Files
- `index.html` — main landing page
- `style.css` — responsive design
- `script.js` — small UI script
- `privacy.html` — privacy policy
- `affiliate-disclosure.html` — affiliate disclosure

## GitHub Pages
1. Create a public GitHub repository, for example: `dealfinder`.
2. Upload all files in this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. GitHub will provide a URL similar to:
   `https://YOUR-USERNAME.github.io/dealfinder/`

## Before publishing
- Replace the placeholder contact paragraph in `privacy.html` with your real public support email.
- When the Chrome extension is live, replace the "In development" section/button with the official Chrome Web Store URL.
- Keep the privacy policy accurate if the extension's data handling changes.
- Do not claim prices, ratings, user counts, savings, or partnerships that you cannot substantiate.
